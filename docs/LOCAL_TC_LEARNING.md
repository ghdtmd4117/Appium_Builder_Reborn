# Local TC Studio · Project Learning

Local TC Studio는 더 이상 `ID / 제목 / 사전조건 / 테스트절차 / 기대결과 / 우선순위 / 유형` 같은 고정 TC 스키마를 기본값으로 강제하지 않습니다.

## 학습 방식

프로젝트별 학습 프로필은 다음 로컬 자료를 조합합니다.

- 사용자가 직접 입력한 TC 작성 규칙
- 기존에 작성한 TC (`CSV`, `XLSX`)
- TC 작성 가이드/기획서 (`PPTX`, `PDF`, `DOCX`, `TXT`, `MD`)
- 관련 화면/기획 이미지 (`PNG`, `JPG`, `BMP`, `GIF`)
- Local TC Studio에서 생성 후 사람이 수정한 현재 TC

`프로필 학습`을 실행하면 로컬 Qwen Vision 모델이 자료에서 컬럼 구조, 작성 규칙, 문장 스타일, 커버리지 습관을 요약합니다. 결과와 대표 TC 예시는 `%LOCALAPPDATA%/AppiumBuilderReborn/TC/tc_learning_profiles.json`에 저장됩니다.

이 기능은 모델 가중치를 재훈련하는 Fine-tuning이 아니라, 프로젝트별 지식 프로필을 지속 저장하고 이후 생성 때마다 컨텍스트로 적용하는 방식입니다.

## 동적 TC 구조

기존 TC 예시가 있으면 관찰된 컬럼명과 순서를 그대로 사용합니다. 서로 다른 구조의 예시가 섞인 경우 가장 많이 관찰된 구조를 대표 스키마로 선택하고 경고를 남깁니다.

기존 스키마가 없으면 사용자가 입력한 규칙과 학습 자료를 근거로 로컬 모델이 컬럼 구조를 제안합니다. 특정 표준 7컬럼을 fallback으로 강제하지 않습니다.

## 피드백 학습

생성된 TC를 사람이 수정한 뒤 `현재 TC 학습 반영`을 누르면 현재 컬럼과 대표 행을 프로필의 학습 예시로 저장합니다. 다음 생성부터 수정된 작성 방식을 참고합니다.

## Privacy

학습/생성 요청은 `127.0.0.1`의 로컬 Ollama runtime에만 전달됩니다. 학습 원본 파일은 프로필에 복사하지 않고 분석 요약, 컬럼 구조, 제한된 대표 예시와 출처 이름만 저장합니다.
